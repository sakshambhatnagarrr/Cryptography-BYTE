# Finding The CTF in Encrypted Text.

**Category:** Cryptography
**Tools:** CipherChef,Cyberchef,dcode.fr

## Summary
Applied Base64, then added the obtained key to dcode.fr to find the key of how much has been shifted and then applied The Key to Vigenere Solver to find the key.

## Solution
1. Applied Base64 to the give text.
2. Added the text to dcode.fr to find the key using "knowing a plain text method" and added the flag format BYTE to it.
3. Added Vigenère Solver to the pipeline and added the key to found.

## Flag
BYTE{sA73_O8C_RihFN_O4pGaO}

## Key Found 
ACPJJ
